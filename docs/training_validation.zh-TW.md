# 新模型訓練：獨立校正與驗收

此功能適用於完整新模型訓練，直接整合在選片、切片審核與完成頁，不需使用舊的「模型考試」。更新後請重新啟動服務，資料庫會自動新增用途與標籤欄位。

## 操作

1. 只選取一次資料，保留預設勾選的「自動校正與驗收」。批次欄由資料夾帶入；只有批次名稱不符實際資料時才需修正，不需手動選用途。
2. 審核頁只依 INNER／EDGE 顯示圖片。先標記 NG，再點「確認其餘為 OK」，已標記的 NG 不會被覆蓋。分配到訓練組的 NG 不會加入 memory bank，未標記資料也不能開始訓練。
3. 需要歷史 NG 與多批次資料時，選手動資料夾來源，勾選「包含下一層批次資料夾」。支援 `根目錄 / 批次 / panel / 光源圖片`，掃描後帶入批次資料夾名稱，請確認其代表實際批次。
4. 有需要時展開「進階：驗收目標」，設定可接受的 OK 誤判率與 NG 漏檢率（百分比）。留白時仍有建議與實測結果，但不會標示符合目標。
5. 完成頁比較原門檻 0.35 與建議門檻，並提供各驗收批次表現、錯判圖片與完整 JSON 報告。
6. 點「採用建議門檻」才會更新該子模型的 YAML 與 thresholds.json，另存採用紀錄。此操作不會啟用模型；已啟用的模型需先停用才能採用。

關閉「自動校正與驗收」時，沿用原正常樣本訓練流程。局部重訓尚未提供自動分組。舊 job 的人工分組仍可繼續使用。

## 自動分組

系統依批次固定分組；同一批次、同一片在不同資料夾的照片不會跨用途。有至少三組互不重疊的批次時，各保留約 20%（至少一組）供校正及驗收，其餘供訓練。比例依批次數計算，不是圖片數。同樣的資料與批次設定，即使選片順序不同，分組結果也相同。

不足三組時全部保留給正常樣本訓練，完成頁會說明尚無獨立校正／驗收，不需為了開始訓練另外挑兩份資料。批次足夠也不保證校正與驗收各有 OK、NG；缺少任一類仍標為資料不足，不會把其他組的圖片搬過來補數。

分組設定會保存在 job 與報告中。目前不會自動沿用另一個 job 的人工標籤；重新選圖仍需確認 OK／NG。

## 判讀

- 校正與驗收資料不加入 memory bank。校正組 OK／NG 可提供模型分數正規化及門檻選擇；驗收組不參與兩者。
- 每個光源、INNER／EDGE 各自計算建議門檻。先找符合已設定限制的門檻，再最小化「OK 誤判率 + NG 漏檢率」；若校正組無可行門檻，報告會說明未達目標。
- 校正或驗收缺少 OK／NG、檔案無法讀取、跨用途存在完全相同的切片等情況，會標為資料不足，不提供可採用的建議。完全相同的正常背景也可能觸發重複檢查，請使用不同影像並重新確認資料。
- 「本次樣本符合目標」是建議門檻在此次樣本上的結果，不代表未來所有批次。請同時看樣本數與各批次結果；切片數不等同獨立 panel 數。
- 這是匯出模型的切片分數驗收，尚未包含灰塵、OMIT、遮罩等產線後處理，不代表最終整片判定。
- 使用同一前處理流程產生的切片，逐張評估並保存到磁碟；不會將全部驗收圖片加入 GPU memory bank。此功能本身不增加訓練資料可容納量。

## 留存與追溯

各子模型在 bundle 的 `validation_reports/<光源-區域>/` 保存輸入清單、標籤、批次、影像雜湊、影像副本、逐張分數與採用紀錄。資料在模型訓練前保存快照。

報告綁定模型 SHA-256 與設定指紋。模型或設定改變後，完成頁將報告標為歷史參考，不能再採用其建議。更改目前門檻不會改寫當初的校正／驗收分數。
