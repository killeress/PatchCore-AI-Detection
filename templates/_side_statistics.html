側拍統計

使用說明
  • 總覽：預設當班，與中控總覽相同；白班 07:30～19:30、夜班 19:30～隔日 07:30，依入庫時間統計。可指定起班日期與白班／夜班，總覽明細僅列 AOI 有 CSJBL 的紀錄，每筆計一次。
  • 排片率：NG ÷ 總投入，ERR 與其他紀錄均列入分母；整體包含所有 AOI 類型。機台、機種與玻璃 ID 有篩選時，只計算該範圍。
  • 明細：點分類篩選明細，再點一次取消。總覽範圍不變。
  • 整片試算：摘要分別列出側拍可轉 OK 點數、剩餘正式 NG 筆數與畫面來源；展開可查看阻擋轉 OK-s 的 NG 原因、座標與分數。側拍點可轉 OK 時，其他正式 NG 仍須保留；同 ID 的不同次檢測分別計算。
  • 檢測狀態：依保存結果區分保留候選、無保留候選與未完成檢測；貼紙、MARK、易撕貼另列系統處理結論。
  • 圖片：紅色 A# 為 AOI 估算位置的 64×64 原圖 px 空心框，黃色標示判定距離容錯內的保留候選；灰色候選只供參考。三張局部圖以相同正方形尺寸直接顯示，原圖保留像素與方向、超出邊界補黑；點圖可在頁內放大並隱藏 AOI 框，原圖無法讀取時使用保存預覽。
  • 比對：CSJBL 由正拍位置估算至側拍。判定距離容錯預設 5 產品 px，可於側拍參數調整；範圍內沒有異常也列為可轉 OK。比對範圍僅控制周邊參考顯示。
  • MARK：沿用同次正式定位及側拍已辨識的 MARK／角落印字範圍。AOI 點或 ROI 涵蓋 MARK 時，只屏蔽實際 MARK 內的候選；報點未命中其他保留候選、未命中炸彈且檢測完整，才列為可轉 OK。新推論符合整筆放行條件時正式轉 OK-s；歷史紀錄保留原判定。
  • OMIT 比對：每個 AOI 點提供正拍、側拍與 SPINIGBI 對照及候選重疊比例。貼紙／灰塵過濾固定啟用；報點候選已排除且未命中其他保留候選，該點才可轉 OK。
  • 貼紙：OMIT 完整覆蓋暗色本體、已啟用屏蔽且 AOI 命中貼紙候選時，該點可轉 OK；其他候選、遮罩空洞、缺圖及未完成檢測仍保留檢查。
  • 易撕貼：獨立使用側拍已辨識的右下角易撕貼範圍（含 180 度旋轉對應位置）。AOI 點須命中實際範圍，未命中其他保留候選與炸彈驗證範圍，才列為可轉 OK；不以整個角落或比對容許距離放行。
